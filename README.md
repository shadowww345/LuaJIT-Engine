# LuaJIT-Engine
## A engine with OpenGL LuaJIT implementation 
**Main LuaJIT OpenGL implementation code: https://github.com/shadowww345/LuaJIT-OpenGL**
### Requirements
**Aten Audio Engine: https://github.com/shadowww345/Aten-Audio-Engine** <br>
``
sudo apt install libpipewire-0.3-dev libglfw3-dev libgl-dev luajit
``
### Features
**Physics** <br>
**Player Movement** <br>
**Loading OBJ** <br>
**Keyframe Mesh** <br>
**Texture Loading** <br>
