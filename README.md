# LuaJIT-Engine
## A engine with OpenGL LuaJIT implementation 
**Main LuaJIT OpenGL implementation code: https://github.com/shadowww345/LuaJIT-OpenGL**
### Requirements
**Aten Audio Engine: https://github.com/shadowww345/Aten-Audio-Engine**
``
sudo apt install libpipewire-0.3-dev libglfw3-dev libgl-dev
``
### Features
**Physics**
**Player Movement**
**Loading OBJ**
**Keyframe Mesh**
**Texture Loading**
